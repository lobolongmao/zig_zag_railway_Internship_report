# 之字形鐵路上的人 · The People of the Zig Zag

羅聖皓 Sheng Hao Lo 於 2026 年 7 月 22 日至 8 月 5 日在澳洲新南威爾斯州 Zig Zag Railway 實習期間的個人成果。中英雙語互動網頁，右上角可切換語言。

A bilingual (Traditional Chinese / English) interactive page made during an internship at Zig Zag Railway, NSW, Australia (22 July – 5 August 2026). This is a personal project, not an official Zig Zag Railway website.

## 用 GitHub Pages 上架 Publish with GitHub Pages

1. 在 GitHub 建立一個新的 repository，把這個資料夾裡的所有檔案上傳（`index.html`、`README.md`、`img/`）。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。
